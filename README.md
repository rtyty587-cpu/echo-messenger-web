# ECHO 1.15.4

Прямое соединение WebRTC проверяется первым: TURN не используется, общий бюджет не расходуется. При неудаче — повторный вызов через сервер. Собеседнику нужно принять повторный вызов. Серверы выбираются из закрытой конфигурации Firebase; резерв использует тот же общий счётчик.

Общий месячный бюджет резервирования — 2 000 000 000 байт на все аккаунты. Каждый участник резервирует 10 МБ на короткий сеанс с продлением. Остаток резерва не возвращается; это консервативное ограничение, а не измерение счёта ExpressTURN. При исчерпании бюджета, ошибке проверки, истечении разрешения или отсутствии счётчиков трафика серверный звонок закрывается. Прямые звонки остаются доступны.

Видео через TURN ограничено 250 кбит/с, звук 32 кбит/с. Сеанс через TURN до часа; новый звонок возможен при наличии бюджета. Прямое подключение не требует общей сети: оно возможно и через разные сети, если маршрутизация позволяет.

Оба собеседника должны обновить ECHO. Оплата и платные тарифы не подключались. Постоянные TURN-данные не включены в публичные исходники, но авторизованный клиент получает их после резервирования. Ограничитель приложения не предотвращает использование извлечённых данных вне ECHO и не является жёстким лимитом провайдера.

Проверки: правила Firestore на локальном тестовом эмуляторе; конкурирующие резервирования, исчерпание, сброс месяца, запрет подделки счётчика и доступа; клиентские проверки срока, байтов, отключения, резерва; TURN allocation UDP/TCP обоих серверов. Реальный звонок между двумя устройствами ещё не подтверждён.
