# ECHO 1.8

Echo Coin: начальный баланс 0. За каждые полные 7 дней после первого запуска версии 1.8 начисляются 10 монет; пропущенные недели начисляются при следующем входе. Покупки и баланс проверяются правилами Firestore.

Магазин: 12 рамок за монеты, выбор купленного в настройках. Аккаунту создателя доступны все рамки и отдельная радужная рамка «Создатель ECHO». «Золото» остаётся золотым.

Обновите все устройства до 1.8. Новые сообщения и вложения шифруются для участников; для переноса на другое устройство сохраните защищённую паролем копию ключей в настройках и импортируйте её на новом устройстве. Старые сообщения автоматически не перешифровываются. Потеря ключей означает потерю доступа к зашифрованной истории. Реализация не проходила независимый аудит; прямой секретности (forward secrecy) нет. Звонки используют зашифрованный обмен сигналами и WebRTC SRTP, требуют проверки между реальными устройствами.

Внешнее хранилище отключено по просьбе владельца. Лимит вложения — 512 КиБ; крупные фотографии сжимаются. Файлы 2 ГБ не поддерживаются. Фоновых уведомлений о звонках нет; оба приложения должны быть открыты.

Android: установите ECHO.apk поверх прежней версии. Windows: распакуйте весь ECHO-Windows.zip, запустите ECHO.exe; нужны .NET Framework 4.8 и WebView2. EXE без подписи издателя.

Сайт: https://rtyty587-cpu.github.io/echo-messenger-web/

Проверены локальные сценарии интерфейса, покупки, начисления, права и шифрование; правила проверены эмулятором Firestore. Владелец подтвердил публикацию правил 15 октября 2026. Проверка с двумя реальными аккаунтами и звонки на физических устройствах ещё не выполнены.
