# ECHO 1.9 — коллекция, розыгрыши и видео

Рамка «Создатель ECHO» убрана из магазина. Она доступна только владельцу в настройках применения рамки. Золото остаётся золотым, плашка Админ переливается.

## Коллекция ECHO NFT
Это внутренние коллекционные предметы за игровые Echo Coin, без блокчейна, криптокошельков, денежных платежей и вывода денег. Тираж продажи общий для всех пользователей. Покупка атомарно списывает монеты и уменьшает остаток; при конкурирующих покупках сервер перепроверяет остаток. Приобретать можно несколько экземпляров одного вида.

| Предмет | Редкость | Цена EC | Тираж продаж |
|---|---|---:|---:|
| Искра | Обычный | 30 | 50000 |
| Лунный свет | Обычный | 40 | 30000 |
| Мятный кристалл | Обычный | 50 | 20000 |
| Комета | Редкий | 300 | 2000 |
| Розовый кварц | Редкий | 500 | 1000 |
| Орбита | Эпический | 2000 | 200 |
| Сердце сверхновой | Эпический | 4000 | 100 |
| Корона космоса | Мифический | 25000 | 12 |
| Мишка ECHO | Легендарный | 1000000 | 3 |

Все виды доступны создателю для оформления, без покупки и уменьшения тиража. Призовые экземпляры выдаются сверх тиража продаж; в личной коллекции отдельно показано число призовых. Счётчик магазина относится только к продажам. В настройках можно поставить предмет в угол аватара и под описанием профиля. Добавлено «О себе» до 300 знаков; профиль друга открывается нажатием на аватар в чате.

## Розыгрыши
После обновления правил и входа создателя автоматически создаётся официальный канал «Розыгрыши ECHO», код EC0000000001. Кнопка входа доступна во вкладке Каналы, подписка подтверждается пользователем. Только закреплённый создатель может публиковать и проводить розыгрыши в этом канале; назначать других администраторов в нём нельзя.

Кнопка подарка рядом с вводом публикации открывает форму: монеты или вид предмета, описание, награда каждому, число победителей, случайный или ручной выбор. Общее число призов рассчитывается автоматически. Участие бесплатно, одна заявка на аккаунт. Максимум 100 победителей, до 1000000 EC или 100 предметов каждому. Условия после публикации неизменны. При подведении итогов заявки закрываются; результат фиксируется единожды. Победитель нажимает «Забрать приз», повторное получение блокируется сервером. Организатор не участвует.

Случайный выбор выполняется Web Crypto в приложении администратора без повторов. Это доверенная организатору жеребьёвка, а не независимо проверяемый серверный случайный выбор. Правила не доказывают случайность списка, отправленного администратором. Сведения о розыгрышах, профили, коллекция и баланс являются серверными данными, не зашифрованными сообщениями.

## Звонки
Добавлены видеозвонки, включение/отключение камеры, сворачивание и возвращение в звонок. Демонстрация экрана через системный выбор окна/экрана доступна в поддерживаемом браузере на ПК и WebView2 Windows; системный звук не передаётся. В Android доступны камера и просмотр демонстрации собеседника. Собственный захват экрана в Android WebView не реализован: кнопка отключена с пояснением. Камера/микрофон запрашивают разрешение. На завершении звонка все локальные медиадорожки останавливаются.

Сигнальные данные шифруются, медиаданные защищены WebRTC. Прежние ограничения остаются: оба клиента должны быть открыты, фоновых уведомлений нет, TURN не настроен, некоторые сети могут не соединиться. Реальные видеозвонки и захват экрана на физических устройствах пока не проверены. Тесты используют имитацию медиадорожек и WebRTC.

## Установка и правила
Сначала опубликуйте весь FIREBASE-RULES.txt через Firebase → Firestore Database → Rules → Publish. Новые правила ещё не опубликованы агентом. Обновление правил обязательно для коллекции, профиля, розыгрышей и новых звонков.

Android 8+: ECHO-1.9.apk ставится поверх старого приложения с сохранённой подписью. Windows 10/11: распакуйте весь ECHO-Windows-1.9.zip в новую папку и запустите ECHO.exe. Нужны .NET Framework 4.8 и Microsoft Edge WebView2. EXE без подписи издателя.

Для переноса зашифрованной истории сохраните и импортируйте парольную копию ключей в настройках; пароль аккаунта ключи не восстанавливает. Старые сообщения не перешифровываются автоматически. Протокол не проходил внешний аудит и не обеспечивает forward secrecy. Вложения по-прежнему до 512 КиБ; внешнее хранилище отключено.

Технические источники: [Android PermissionRequest](https://developer.android.com/reference/android/webkit/PermissionRequest), [WebRTC replaceTrack](https://developer.mozilla.org/en-US/docs/Web/API/RTCRtpSender/replaceTrack), [Screen Capture API](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia).
