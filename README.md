# ECHO 1.15.1

Исправлен тупиковый экран при сохранённом входе и отсутствии локальной истории. Теперь можно ввести обычный пароль для автоматического восстановления, открыть приложение без восстановления или явно начать новые переписки. Последний вариант сохраняет старые сообщения на сервере, но не восстанавливает потерянные закрытые данные.

Обновление защиты сохраняет прежние открытые данные для проверки подписей. При входе со старого устройства сохранённая там история объединяется с текущей защищённой копией (до 8 предыдущих наборов). Собеседникам требуется ECHO 1.15.1 после обновления защиты.

Смена пароля аккаунта и дополнительная блокировка переписок сохранены. Пароли не записываются в Firestore. Правила обновлены для владельца аккаунта. Локальные тестовые серверы не запускались.
