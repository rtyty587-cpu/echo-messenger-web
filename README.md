# ECHO 1.12.0

Ауры вместо рамок: купленные предметы и выбранное оформление сохранены. Аура ECHO Premium доступна с подпиской.

В заголовке диалога, группы или канала нажмите «⋯»:
- Найти сообщения — поиск по тексту и названию вложения, расшифровка локально. Кнопка продолжения проверяет более раннюю историю порциями по 200 сообщений.
- Очистить историю у меня — скрыть сообщения до момента очистки на ваших устройствах.
- Удалить чат у меня — скрыть разговор из списка. Чтобы вернуть, введите код друга, группы или канала.
- Удалить чат у всех — закрыть разговор. Личный диалог может закрыть любой участник; группу/канал только создатель. Отмена не предусмотрена. Доступ к сообщениям закрывается правилами Firebase, зашифрованные записи остаются в базе, скачанные участниками копии не удаляются.

Перед использованием новых действий опубликуйте FIREBASE-RULES.txt в Firebase → Firestore → Rules → Publish. Обновите все клиенты. Сначала проверьте действия на тестовой группе.

Android: установите ECHO-1.12.0.apk поверх предыдущей версии, не удаляя данные приложения.
Windows: распакуйте ZIP целиком и запустите ECHO.exe; DLL и папку assets оставьте рядом.

Файлы до 512 КБ. Фоновых push-уведомлений нет; звонки работают при открытом приложении. Экран транслируется с ПК. Шифрование не проходило независимый аудит. Сохраните резервную копию ключа.
