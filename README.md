# ECHO 1.15.2

Прямые звонки без платного или пробного сервиса. Перед отправкой зашифрованных offer/answer собираются ICE-кандидаты (до 8 секунд), которые включаются в SDP. Дополнительные кандидаты отправляются после публикации документа звонка. Устранён повторный слушатель кандидатов. Ошибки обмена теперь учитываются в диагностике без записи IP-адресов или текста переговоров.

Настройки защиты и переписка не менялись. Правила Firebase менять не нужно. TURN не подключён: сети, в которых прямое WebRTC-соединение невозможно, по-прежнему требуют ретранслятор. Полный звонок между двумя пользовательскими устройствами не проверялся.
